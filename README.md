## On my desk right now

**VerifierProbe**, a research toolkit that attacks DNN verifiers, built on α,β-CROWN. Verifiers certify a network as safe using exact math, but real networks run in float32. I'm hunting for the inputs that fall into that gap, where a verifier says "certified safe" and the network is still wrong, and building tooling to see what the verifier is actually computing along the way.
